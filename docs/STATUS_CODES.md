# 状态码说明文档

## 概述

本文档详细说明了系统中各种状态码的含义和使用场景。所有状态都使用数字表示，便于数据库存储和 API 传输。

## 用户状态 (User Status)

| 状态码 | 状态名称 | 描述 | 使用场景 |
|--------|----------|------|----------|
| 1 | 激活 (Active) | 用户账户正常，可以正常使用所有功能 | 默认状态，新注册用户 |
| 2 | 停用 (Disabled) | 用户账户被管理员停用，无法登录 | 管理员封禁用户 |
| 3 | 删除 (Deleted) | 用户账户被软删除，保留数据但不可用 | 用户注销账户 |

### 状态转换规则

- **激活 → 停用**: 管理员操作，可恢复
- **激活 → 删除**: 用户主动注销，可恢复
- **停用 → 激活**: 管理员恢复
- **删除 → 激活**: 管理员恢复（需要重新验证）

## 邮箱状态 (Mailbox Status)

| 状态码 | 状态名称 | 描述 | 使用场景 |
|--------|----------|------|----------|
| 1 | 激活 (Active) | 邮箱正常，可以收发邮件 | 默认状态，新创建邮箱 |
| 2 | 停用 (Disabled) | 邮箱被管理员停用，无法收发邮件 | 管理员封禁邮箱 |
| 3 | 删除 (Deleted) | 邮箱被用户删除，可以重新申请 | 用户主动删除邮箱 |

### 状态转换规则

- **激活 → 停用**: 管理员操作，可恢复
- **激活 → 删除**: 用户主动删除，可重新申请
- **停用 → 激活**: 管理员恢复
- **删除 → 激活**: 重新申请后激活

## 邮箱申请状态 (Application Status)

| 状态码 | 状态名称 | 描述 | 使用场景 |
|--------|----------|------|----------|
| 1 | 待审核 (Pending) | 申请已提交，等待管理员审核 | 用户提交申请后 |
| 2 | 已批准 (Approved) | 申请已通过，邮箱已创建 | 管理员批准申请 |
| 3 | 已拒绝 (Rejected) | 申请被拒绝，不能创建邮箱 | 管理员拒绝申请 |

### 状态转换规则

- **待审核 → 已批准**: 管理员批准
- **待审核 → 已拒绝**: 管理员拒绝
- **已批准/已拒绝**: 终态，不可转换

## 邮箱历史操作类型 (Action Type)

| 状态码 | 操作类型 | 描述 | 触发条件 |
|--------|----------|------|----------|
| 1 | 创建 (Created) | 邮箱被创建 | 管理员创建或申请通过 |
| 2 | 删除 (Deleted) | 邮箱被删除 | 用户主动删除 |
| 3 | 停用 (Disabled) | 邮箱被停用 | 管理员停用 |

## 安全审计操作类型 (Security Action Type)

| 状态码 | 操作类型 | 描述 | 使用场景 |
|--------|----------|------|----------|
| 1 | 权限拒绝 (Permission Denied) | 用户尝试访问无权限的资源 | 越权访问尝试 |
| 2 | 可疑操作 (Suspicious Operation) | 检测到可疑的系统操作 | 异常行为检测 |

## 安全审计攻击类型 (Attack Type)

| 状态码 | 攻击类型 | 描述 | 使用场景 |
|--------|----------|------|----------|
| 1 | 权限拒绝 (Permission Denied) | 尝试访问无权限资源 | 越权攻击 |
| 2 | 可疑活动 (Suspicious Activity) | 检测到可疑活动模式 | 行为异常 |
| 3 | 频率限制 (Rate Limit Exceeded) | 超过频率限制 | 暴力攻击 |

## 数据库字段说明

### deleted_at 字段

- **类型**: DATETIME
- **可空**: 是
- **用途**: 记录软删除的时间
- **使用场景**: 
  - 用户状态为 3 (删除) 时记录删除时间
  - 邮箱状态为 3 (删除) 时记录删除时间
  - 用于数据恢复和审计

## API 使用示例

### 查询激活状态的用户
```sql
SELECT * FROM users WHERE status = 1;
```

### 查询被删除的邮箱
```sql
SELECT * FROM mailboxes WHERE status = 3 AND deleted_at IS NOT NULL;
```

### 查询待审核的申请
```sql
SELECT * FROM mailbox_applications WHERE status = 1;
```

## 前端显示映射

### 用户状态显示
```typescript

  switch (status) {
    case 1: return '激活';
    case 2: return '停用';
    case 3: return '已删除';
    default: return '未知';
  }
};
```

### 邮箱状态显示
```typescript

  switch (status) {
    case 1: return '正常';
    case 2: return '已停用';
    case 3: return '已删除';
    default: return '未知';
  }
};
```

## 注意事项

1. **状态一致性**: 确保前后端使用相同的状态码定义
2. **软删除**: 删除操作使用软删除，保留数据用于审计
3. **权限控制**: 只有管理员可以修改用户和邮箱状态
4. **数据恢复**: 软删除的数据可以通过管理员操作恢复
5. **审计追踪**: 所有状态变更都会记录在历史表中
